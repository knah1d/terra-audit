# Browser appearance

System (the monitor icon) follows device light/dark mode, including changes
while the page is open. It is the default without a saved browser preference.

Light and Dark override device mode. next-themes remembers the selection in
browser localStorage and synchronizes it between tabs. Select System again
to resume following the device.

No theme API calls or database migrations are needed. Preferences stay in
this browser. Account data/cache isolation remains unchanged.
